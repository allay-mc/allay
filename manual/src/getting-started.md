# Getting Started

To create a new Allay project, use the following command:

```console,icon=%gnubash,fp=Console
allay create
```

This will prompt you through several questions and create a scaffolding for a new Allay project.
Enter the directory created by Allay and you will see a scaffolding for your project that looks
something like this (depending what template you've selected):

    .
    ├── allay.toml
    └── src/
        ├── BP/
        ├── RP/
        ├── SP/
        └── WT/
