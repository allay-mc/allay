# Contributing

## Working on templates

When templates in stored `./crates/cli/src/templates/std` are edited, make sure
to remove the old templates:

```shell
rm -r ~/.local/share/allay/templates/*
```

The updated templates will be updated in the file system by Allay automatically
on the next invocation of the `allay` command.
